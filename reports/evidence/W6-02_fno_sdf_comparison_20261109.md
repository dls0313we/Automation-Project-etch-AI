# FNO 정답 SDF 수신 및 샘플 깊이·CD 계산 확인

2026-11-09 로컬 실행 기록입니다. GitHub 업로드·CI 결과가 아닙니다.

## 범위와 구현

- 정답 SDF 파일 400개, 707,837,412 bytes. 이름 기준 train 300 / validation 40 / test 40 / OOD 20.
- 별도 NumPy 검사로 400개 phi 헤더 [T,128,256] float32 및 t000..tN 번호를 확인했습니다. 마지막 번호 범위는 3~20입니다. 전체 SDF의 물리 정확도를 검사하지는 않았습니다.
- 실제 비교 범위는 예측 샘플이 있는 validation r0301/r0307/r0325, onestep/rollout 98개 프레임입니다.
- `fno_sdf_compare.py`는 표준 라이브러리로 명시된 단계·격자·7개 파라미터를 대응하고 깊이 및 CD 3개 높이의 제공값을 비교합니다.
- 새 출력 폴더에 HTML, CSV, JSON, SVG를 기록하며 기존 결과와 입력 파일을 수정하지 않습니다. 개인 경로는 로컬 설정에만 있습니다.

## 실제 확인 결과

- 깊이·CD 관련 숫자 576개 일치. 최대 차이: 1.1182502035467223e-8 µm / 1.0201330618020421e-6 퍼센트포인트.
- 원본 CSV 빈칸 12개는 정답 폭 0으로 비율이 정의되지 않는 경우이며 미측정으로 유지했습니다.
- NumPy로 독립 작성한 격자 모서리 최저점·수평 단면 보간으로도 576개와 누락 12개를 확인했습니다. 표준 라이브러리 결과와의 최대 차이는 8.89e-16 µm / 4.27e-14 퍼센트포인트 이하입니다. NumPy는 제품 코드의 의존성이 아닙니다.
- 읽은 입력들의 전후 SHA256 일치. 기존 평가 점수 요약과 판정 코드·임계치 파일 해시도 이전 기록과 일치합니다.
- 실제 FNO 어댑터 재실행에서 두 방식 모두 HOLD, 실제 학습·교체 False입니다.
- 전체 172개 테스트 통과. 새 모듈·테스트 및 수정한 VTP 비교 모듈의 ruff 검사 통과. 새 두 파일의 ruff format --check 통과. 기존 로컬 어댑터 전체를 새로 형식 정리하지는 않았습니다.
- HTML의 사례 6개, SVG 12개와 양수 viewBox, 정답·예측 경로를 구조 검사했습니다. 앱 브라우저의 로컬 파일 URL 정책으로 화면 미리보기는 완료하지 못했고 우회하지 않았습니다.

## 해석 제한

이 일치는 계산된 평가값과 제공 CSV의 일치입니다. 예측이 정답과 같다는 의미가 아닙니다. r0307 rollout의 깊이·바닥 폭 차이는 그대로 남습니다.

깊이는 선형 보간한 경계 꼭짓점의 최저점으로 계산했습니다. 제공자의 0.1 µm 재표본화 코드 자체가 동일하다고 주장하지 않습니다. Chamfer·IoU·전체 validation 예측 및 참값의 물리 정확도는 이번 검사의 범위가 아닙니다. 수치 비교 허용차는 모델 합격 임계치가 아닙니다. `reference_verified=false`, 기존 HOLD 및 실제 학습·교체 미실행을 유지합니다.
