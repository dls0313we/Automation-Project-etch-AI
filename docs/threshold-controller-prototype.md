# DOC-HARNESS-001: 임계치 판정기 선행 시연

- 관련 작업: W5-04, W6-02의 선행 프로토타입 공유. 체크리스트 완료 표시는 변경하지 않는다.
- [확인] 코드는 `prototypes/threshold_controller/`에서 독립 실행한다.
- [제안] 가상 형상 오차/깊이 오차/형상 이상 건수로 모델 유지와 재학습 요청 등을 시연한다.
- [미확인] 평가 담당자의 실제 지표, 계산/집계 정의, 공식 임계치, 실제 입력 연결.

## 기존 설계와 차이

기존 설계 C5는 골든셋, CD/깊이 상대 오차, 직전 모델 대비 변화 등을 포함하고,
W5-04는 정상 모델 validation 중앙값을 바탕으로 임계치를 산출하도록 되어 있다.
이번 독립 시연은 µm 단위의 임의 상한과 가상 점수로 파일 입력/판정/기록 흐름만 확인한다.
설계의 기준 산출이나 공식 회귀 게이트를 구현 완료한 것으로 취급하지 않는다.

프로토타입의 APPROVE_CANDIDATE는 권고이며 champion을 변경하지 않는다.
자동 재학습 반복, 데이터 생성, 레지스트리 쓰기, 실제 평가기 호출은 수행하지 않는다.
기존 `src/etchpipe`, 공식 metrics/gate 스키마, 의존성 고정 파일은 그대로 보존한다.

## 이후 연결 조건

평가 담당자와 지표 이름/단위/경계/집계/평가 데이터 및 학습 데이터 준비 기준을 맞춘다.
validation과 모니터링 용도를 정하고, 공식 허용 오차를 확인한다.
기존 인터페이스에 통합 변경이 필요하면 상위 규칙에 따라 별도 ADR로 검토한다.

## 실제 점수 연결 (2026-11-09 추가)

- [확인] `fno_adapter.py`, `mgn_adapter.py`, `run_review.py`로 평가 담당자가 제공한 FNO·MGN 점수를 읽어
  4개 조합(FNO/MGN × onestep/rollout)의 임시 비교와 판정(HOLD)을 기록한다. 점수를 새로 계산하지 않는다.
- [확인] 모델별 Chamfer 정의가 달라 별도 평가 계약 ID를 쓰고, 두 모델의 점수로 우열을 매기지 않는다.
- [제안] 임시 상한은 근거 없는 시작값이며 설계 C5/W5-04의 기준 산출 방식으로 대체되어야 한다.
- [미확인] 평가 담당 정의(점-선분 Chamfer)와의 일치, 형상 이상·자기교차 측정, 정답 자료 대조.
- 실행 기록: `reports/evidence/W6-02_fno_mgn_review_20261109.md`.

## 형상 검사와 정답 비교 (2026-11-09 추가)
